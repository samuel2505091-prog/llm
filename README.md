# Módulo 7 — LLM

Repositorio de entrega del módulo 7 del curso de Inteligencia Artificial.

## Entrega

**Proyecto 3: Sistema de atención al cliente automatizado**

Carpeta: [`atencion_cliente/`](./atencion_cliente)

Asistente de soporte para una tienda en línea, construido sobre la API de OpenAI y operado desde la terminal. Atiende consultas de pedidos, recomienda productos del catálogo, explica políticas comerciales y escala a un agente humano cuando el caso lo requiere. Las consultas de datos se resuelven mediante function calling contra una base simulada.

Las instrucciones de instalación y ejecución están en el README de esa carpeta.
